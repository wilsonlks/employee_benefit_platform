# 同事福利

內部員工福利平台的可互動原型，對應「員工內部福利平台」初步構思：醫食住行優惠集中展示，由人事部把關。

## 可以試什麼

- 以一般員工或人事部身份進入。正式版本會連接公司帳號，這個示範直接選擇角色。
- 按六大分類瀏覽，或用關鍵字、最新、限時、即將完結篩選。
- 打開優惠詳情，查看使用方法、地點、期限，並可複製優惠碼。
- 收藏常用優惠。收藏跟目前的身份走。
- 參加團購。達標後仍可報名，直到截止；截止時未達門檻會自動取消。
- 人事部可上載、編輯、上架、下架和刪除優惠及團購，並查看報名名單。同事只看到總人數。

示範資料裡已放有上架中、即將開始、草案、已過期，以及報名中、已達標、成團成功、未達標取消的例子。

## 本地運行

```bash
npm install
npm run dev
```

瀏覽器打開終端機顯示的本機網址。資料存在這個瀏覽器的 localStorage。右上角選單可以「還原示範資料」。

商戶、價格和同事姓名都是虛構的，沒有連接真實人事系統或廣告商。
