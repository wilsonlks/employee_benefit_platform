# 同事福利

內部員工福利平台的可互動原型，對應「員工內部福利平台」初步構思：醫食住行優惠集中展示，由人事部把關。

## 可以試什麼

- 以一般員工、人事專員或人事主管身份進入。正式版本會連接公司帳號，這個示範直接選擇角色。
- 按六大分類瀏覽，或用關鍵字、最新、限時、即將完結篩選。
- 打開優惠詳情，查看使用方法、地點、期限，並可複製優惠碼。有海報的項目只在詳情頁顯示圖片。
- 人事部上載優惠或團購時，可以選擇上傳海報。這一欄不是必填，沒有圖片也可以提交。
- 收藏常用優惠。收藏跟目前的身份走。
- 參加團購。達標後仍可報名，直到截止；截止時未達門檻會自動取消。
- 人事專員上載優惠後，項目進入待審核。人事主管一鍵「批准上架」，該優惠會立刻出現在員工首頁；也可以退回修改。
- 主管後台有近 30 日瀏覽數據，按六大分類比較哪類優惠最受歡迎，方便之後採購福利。
- 人事部可編輯和刪除優惠及團購，並查看報名名單。同事只看到總人數。

示範資料裡已放有上架中、即將開始、待審核、已退回、已過期，以及報名中、已達標、成團成功、未達標取消的例子。聖誕市集餐飲券和動感健身目前待主管批准。

## 本地運行

```bash
npm install
npm run dev
```

瀏覽器打開終端機顯示的本機網址。資料存在這個瀏覽器的 localStorage。右上角選單可以「還原示範資料」。
